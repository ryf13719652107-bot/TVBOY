开仓后止损（合约）

开启后，每次非仅减仓的市价成交完毕，会按成交数量挂止损单（优先 STOP 限价触发，失败则 STOP_MARKET）。所有账户在各自 API 上独立挂单。仅 BINANCE_DEFAULT_TYPE=future 时生效。

默认 3.33%；设置保存在服务器 data/bot_settings.json。平仓/减仓（reduce_only）不会挂止损；全平后服务端会按交易所持仓是否已空自动撤未触发止损（无需改 Pine）。

TV 策略告警消息（自动推断开/加/减/平）

在策略的「告警」里使用下方 JSON（须为合法 JSON）。本服务会读 action（或 strategy.order.action）与 prev_market_position：在 合约（BINANCE_DEFAULT_TYPE=future） 下，若上一笔为多头且本次为 sell 则自动下仅减仓；上一笔为空头且本次为 buy 同理。开多/加多、开空/加空为非仅减仓。若消息里显式写了 reduce_only，则以你写的为准。多账户优先按模板比例（需服务端配置 TEMPLATE_BASE_CAPITAL_USDT，且告警含 contracts）换算币数；不满足条件时回退为各账户「固定 USDT」。

勿在 JSON 里写 {{price}}*0.95 这类非法表达式；你举的第三方模板若含此类字段，需删掉或改成 TV 能展开的数字，否则整段无法解析。

全平后撤销止损：仅减仓成交后服务端会查询币安该合约持仓，若已空仓则自动取消未触发的止损挂单，不必改 Pine 策略；若告警里带有 market_position=flat 等字段也会作为辅助判断。
